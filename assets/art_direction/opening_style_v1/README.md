# Opening-screen art kit — v1

Created 2026-09-26 using the built-in OpenAI image-generation tool. Style reference: assets/settlement3d/runtime/interface/title_settlement_v1.png. Pre-generated AI images, separate from KayKit assets; no runtime generation.

## Files and readiness

- settlement_kit_reference_v1.png: six building designs plus fir, broadleaf tree, rocks, fence, lantern and cart. A single opaque modeling reference sheet, not separate sprites or 3D meshes.
- roof_slate_basecolor_v1.png: candidate green slate color texture. Contains stylized crevice shading; not a physically neutral measured albedo.
- meadow_ground_basecolor_v1.png: candidate muted meadow color texture.

Visually reviewed against the title artwork. Both textures still need edge continuity, repetition and game-camera scale checks. This folder is excluded from Godot import by .gdignore. The reference sheet now has a first playable adaptation: twelve authored mesh scenes in assets/settlement3d/runtime/opening_style, generated by tools/build_opening_style_models.gd. The two raster texture candidates remain unused; the models have geometric shingles and authored materials.

## Integration sequence

1. Create a playable art sample around the founding town hall: terrain material, matching cottage, angular firs, stone and timber props. Preserve gameplay footprints and navigation.
2. Give new meshes separate roof, stone, timber and window surfaces. Existing vendor palette UVs cannot receive these textures as drop-in replacements.
3. Pair muted greens and warm limestone with amber window emission and cool forest shadows. Tune day and night separately for unit and hazard readability.
4. Inspect actual normal/strategic camera screenshots, texture repetition, fog, selection, shadows and performance before expanding the set.
5. Extend the approved environment style to remaining buildings while preserving existing character rigs and animations.

## Exact generation prompts

### settlement_kit_reference_v1

Use case: concept-art. Asset type: production art reference sheet for the existing 3D strategy game Shard & Sovereign. Input image is STYLE REFERENCE ONLY: match its crafted faceted medieval architecture, muted pine-green slate roofs, warm pale limestone, dark oak timber, glowing amber windows; retain cozy civilization versus cold wilderness identity. Generate a clean landscape asset design sheet on plain light warm grey, no text, no lettering, no UI. Clearly separated fully visible individual objects in three tidy rows, consistent orthographic three-quarter isometric view, no overlapping: first row a modest founding town hall (not enormous castle), timber-framed cottage, covered storehouse; second row lumber camp with logs and saw, bakery with chimney, wooden watchtower with stone base; third row angular fir tree, broadleaf tree, clustered grey rocks, timber fence section, lantern post, handcart. Proportions suitable for readable small 3D game units, realistic stylized proportions not cute toy blobs. Restrained detail, planar silhouettes and convincing construction. Neutral studio illumination with subtle contact shadows; amber windows only local glow. This is a modeling reference sheet, not a screenshot. Derive design language closely from reference buildings and foreground trees.

### roof_slate_basecolor_v1

Use case: texture. Asset type: square seamless tileable base-color texture for a 3D medieval roof material. Input image is STYLE AND PALETTE REFERENCE ONLY. Generate one full-bleed orthographic flat texture of overlapping rows of muted dark pine-green slate shingles matching the settlement roofs in the reference. Broad hand-cut polygonal slates, restrained painted surface variation, subdued teal-green and charcoal, occasional subtle moss tint, staggered horizontal courses, consistent medium scale about 10 tiles across. Physically flat neutral diffuse illumination; no directional light, no cast shadows, no ambient occlusion gradients, no perspective, no building, no border, no text, no swatch sheet. Design opposite edges to repeat seamlessly in both directions. Opaque RGB base color, no normals or channels packed. Readable stylized low-poly painterly material, not photographic grit.

### meadow_ground_basecolor_v1

Use case: texture. Asset type: square seamless tileable terrain base-color texture for a 3D strategy game. Input image is STYLE AND PALETTE REFERENCE ONLY. Generate one full-bleed flat top-down texture of muted olive meadow ground matching the warm settlement grass in the reference. Broad soft irregular patches of dry sage green, olive, muted ochre grass and a little dusty earth; sparse tiny flat grass strokes, very restrained texture for viewing beneath buildings and units. No isolated large rocks, no flowers, no roads or tracks, no objects, no grass clumps with silhouette shadows. Neutral flat diffuse illumination, no baked sunlight, no dark vignette, no directional shading. No horizon or perspective, no border, no text, no grid or swatch sheet. Opposite edges designed to tile seamlessly both directions. Opaque base color image. Painterly faceted natural color regions, never bright neon green or photorealistic grass.
