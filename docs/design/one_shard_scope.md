# One Shard Scope

## Objective

Build a small isometric logistics prototype where a woodcutter produces wood and a carrier moves that wood to a warehouse.

## Included Features

- Isometric tile map
- Camera pan and zoom
- Tile selection
- Building placement
- Warehouse
- Woodcutter
- Wood resource
- Carrier worker
- Basic pathfinding
- Production loop
- Hauling loop
- Warehouse inventory display
- Save/load
- Debug overlay

## Excluded Features

- Multiplayer
- Combat
- Enemies
- Market economy
- Complex construction chains
- Multiple resources
- Roads
- Caravans
- Territory politics
- Procedural map generation
- Account system
- Online persistence

## Success Criteria

The prototype succeeds when the player can:

1. Start a local game.
2. See an isometric world.
3. Place a warehouse.
4. Place a woodcutter.
5. Watch wood get produced.
6. Watch a worker carry wood to the warehouse.
7. See warehouse wood inventory increase.
8. Save the world.
9. Load the world.
10. Inspect the simulation through debug tools.
