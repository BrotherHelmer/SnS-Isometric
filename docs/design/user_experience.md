# User Experience

## Target Feeling

The player should feel like the founder of a small medieval settlement. The first satisfying moment is not expansion or conquest; it is seeing a simple local economy begin to work.

## First Play Session

The intended first session is:

1. Open a local prototype.
2. Pan and zoom across a small isometric map.
3. Select a tile.
4. Place a warehouse.
5. Place a woodcutter.
6. Watch wood appear in the woodcutter output.
7. Watch a carrier move wood to the warehouse.
8. See the warehouse inventory increase.
9. Save and load the same world.

## Interface Bias

The first interface should be practical and transparent. Debug visibility matters more than polish.

The player should be able to inspect:

- Selected tile
- Selected building
- Worker state
- Current task
- Inventory
- Path
- Production state
- Save/load status

## Visual Bias

Use readable placeholders until the logistics loop works. The world should be legible before it is pretty.
