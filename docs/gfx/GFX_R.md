# GFX-R: silhouette, geology, density

Stacked on GFX-Q (`cursor/gfx-q-visual-pass-a689`, `182863a`, PR #74,
ChatGPT **7.3/10**, +0.2 vs P). ChatGPT's review is in
`uploads/CHATGPT_ANSWER_GFXQ.md`. Helmer's holiday bar is still a
playable demo ChatGPT rates **≥ 8/10**. Target **8.5**.

**Rule:** only what is visible at native **1280×720** gameplay cameras
counts. Showcase shots are clean — no RAID popup.

**Keep:** occupancy, distance-field roads, KayKit houses / mill, meadow
baseline, forest, fog, west creek, Q limestone / teal slate, night, and
grade knobs (sat 1.12 / contrast 1.12 / exposure 0.86).

**Exception:** day *light* may move. Night stays frozen.

## Order

1. **Castle silhouette.** Raised keep, three roof masses, one tall
   asymmetric tower, battlements, gate, dark window recesses, banner.
2. **Ridge geology.** Grassy slopes, rock outcrops, layered ledges,
   trees at the base, a broken skyline.
3. **Environmental density.** MultiMesh tufts / flowers / shrubs /
   stones in settlement, meadow and forest-edge zones.
4. **Roads, water, footprints.** Irregular aprons, varied widths,
   stronger ruts, creek swung into the visible meadow.
5. **Warm late-afternoon day light.** Softer shadows, readable smoke /
   workers / window panes at 720p.
