# Shard & Sovereign — CC0 Settlement SFX v3 Provenance

All output files are curated/edited from **CC0** (Creative Commons Zero / public domain dedication) source recordings.
No Settlers/Amiga/commercial game audio was used. No procedural sine/beep synthesis was used for these slots.

**Target format:** WAV, 44.1 kHz, 16-bit PCM, mono, peak ≈ −1 dB, short fades (5–15 ms) to kill clicks.

**Build date:** 2026-09-27 (Europe/Copenhagen)

## Gaps

- **soldier.wav** — No dedicated medieval horn fanfare in the CC0 packs fetched; Kenney Steel jingle is the best CC0 military-ready ack available. Warmth is present; not an authentic brass horn recording.
- **night.wav / enemy.wav** — Dark stinger and abyss are composed/synth-leaning (still CC0 game assets, not sine-beep placeholders). Layered with recorded growls (enemy) where possible.
- **road.wav** — Uses short gravel/stone footsteps rather than prolonged road-laying foley; length fits UI/action cue (~0.45 s).
- **FGResources collection** page itself has no single zip; gravel/stone taken from the linked CC0 “Different steps…” item (qubodup).
- Kenney Impact Sounds **did download successfully** (official kenney.nl zip + cc0-sounds.exi.software mirrors). Do not claim Kenney downloads failed.
